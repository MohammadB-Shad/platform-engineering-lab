# Platform Engineering Lab

## Project Overview

This project is a hands-on DevOps and Platform Engineering learning environment.

The goal is to design, build, operate and troubleshoot a production-like infrastructure from scratch.

## Scenario

We will simulate a real company environment and gradually build its infrastructure.

## Learning Goals

- Linux Administration
- Networking
- Git and Git Workflow
- Docker
- CI/CD
- Kubernetes
- Monitoring
- Logging
- Security
- Infrastructure Automation
- AI Automation

## Environment

Virtualization:
- VMware Workstation

Version Control:
- GitHub

## Project Approach

We will follow a production-oriented approach:

Requirement → Design → Implementation → Operation → Troubleshooting → Automation
